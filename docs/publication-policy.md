# 公開內容與權限

目前遠端為 public。建議只提交自行撰寫的公開筆記、必要書目與規則，不提交付費 PDF、整篇抽取文字、未發表研究假設、審稿意見、受訪者／實驗參與者資料、登入憑證或私人雲端連結。開放全文也優先放合法連結；欲重散布須先確認授權。

private/、fulltexts/ 與常見全文檔案已被忽略；私人筆記放 private/notes/，主表 note_path 留空，直到有公開版。reading_status=read 的公開主表須連公開版筆記；若無法公開筆記，應把整筆閱讀紀錄留在私人工作副本，公開主表只保留 screened 索引。

.gitignore 不是存取控制，也不移除既有 Git 歷史。檔案被強制加入仍會公開；提交前人工查看變更。第一版不預設開源授權，不含 LICENSE，後續由擁有者決定可授權內容與條款。
